# Cohort6 Github Cheatsheets

## Basic Commands
- git init
- git status
- echo "My first Github project" > README.md
- git add .
- git commit -m "Hello World!"
- git log
- git pull
- git push -u origin main

## Working with branches
- git branch 
- git switch -c feature/add-notes 
- git switch main

## Cloning an existing repo
1. git clone git@github.com:William-Muko/cohort6-git-repo.git
2. cd "Repo"
